# Ome365 — Open-Source Enterprise AI Platform · Live Demo

> **Tagline**: Run your company on agents, not org charts.
> **Sub**: Your AI follows the employee, not the employer.

This is a **read-only demo** of [Ome365](https://github.com/wyonliu/Ome365). Click around to see:

- 📊 **Dashboard** — your day · week · quarter at a glance
- 🧠 **Hike** entity graph — cross-meeting people / orgs / products knowledge
- 📝 **Notes / Journal / Plan** — markdown-first PKM
- 🔗 **Share station** — argon2 + Fernet-encrypted public link sharing
- 🔬 **Cockpit** — config-driven dashboards for executive review

⚠️ **Demo limits**:
- Data resets every restart (don't store real PII)
- LLM and embedding backends disabled (read-only · no AI inference)
- No login (auth_provider=none)

## Want to self-host?

```bash
# One-line install (macOS / Linux / WSL)
curl -fsSL https://raw.githubusercontent.com/wyonliu/Ome365/main/install.sh | sh
```

Or `git clone https://github.com/wyonliu/Ome365.git && ./ome365`.
