## 一 · 设计原则

| # | 原则 | 含义 | 没遵守的代价 |
|:---:|:---|:---|:---|
| 1 | **file-first** | 所有信息以 markdown 落盘 | 失去 git diff / rsync / audit 优势 |
| 2 | **派生 lazy 计算** | 7 维评分等永不写盘·永远 grep 重算 | vault 不再是 ground truth |
| 3 | **零强制启用** | 4 文件夹都可选·缺了也跑 | 单用户场景被组织功能压重 |
| 4 | **Anthropic SKILL.md 100% 兼容** | 32 工具读同一份 SKILL.md | 失去 Agentic Web 红利 |
| 5 | **append-only logs** | Trace/ 只能 append·git pre-commit hook 强制 | 评分可被人工篡改 |
| 6 | **GDPR Art. 22 enforcement** | 评分不可作为人事决策唯一依据 | 法律风险·OSS 责任 |
| 7 | **tenant-scoped** | 所有派生函数接 tenant_slug | 多租户数据混淆 |
| 8 | **可演进的 schema** | frontmatter 字段可加不可删 | 旧 vault 不向后兼容 |
| 9 | **outcome > token** | D2/D6 用 ROI 不用 Token 量·反 Tokenmaxxing | 沦为 performative AI 工具 |
| 10 | **MCP 2026 路线对齐** | Progressive Discovery + Code Mode + AAIF agent-card | 错失生态接入 |

**CI 双层校验**（拆 spec compatibility 与 runtime tested · 不混淆 over-promise）：

1. **Spec lint (32/32 tools · `tests/test_skill_lint.py`)**：静态校验 Anthropic SKILL.md frontmatter 字段 + namespace（`name` / `description` / `allowed-tools` / `license` / 自有扩展走 `ome365:` 命名空间）·100% headless·覆盖全部 32 个 spec adopter。
2. **Runtime tested (3-4 headless CLIs · `tests/skill_interop_test.sh`)**：真在 **Claude Code + Codex CLI + Gemini CLI + Continue.dev** install + load + execute + verify 全流程·失败阻塞合入·**IDE hosts (Cursor / JetBrains Junie / AWS Kiro / Block Goose 等) 不进 CI**·靠社区 verify。

文档 / README / show-hn 措辞统一："spec-compatible with 32 tools · runtime-tested on 3-4 headless CLIs"·**禁止 "32 tools CI verified" 这种 over-promise**。

#### 3.2.3 `Decisions/<id>.md` · 8 步范式（5 AI + 3 human · 含 value_anchors）

```yaml
---
id: 2026-05-08-vendor-pick
opened: 2026-05-08T14:00:00Z
closed: null
status: open                  # open | closed | superseded
owner: alice
participants: [bob, carol]
supersedes: null
superseded_by: null
outcome: null
# 🆕 industry value-anchor pattern · tag at close · don't wait 90-day USD backfill
value_anchors:                # P / XL / L / M / 维护性 / Revert
  - P                         # 推动产品增长
  - L                         # 规模 Large
roi_estimated: null           # 0-90 天用 value_anchors
roi_actual: null              # 90 天后回填的 USD
---
# Decision: Pick vendor for X

## ① Problem definition (human)        ← 人 · any role
## ② Data needs (AI)                   ← AI
## ③ Models considered (AI)            ← AI
## ④ Options (AI)                      ← AI
## ⑤ Decision (human · leader)         ← 人 · CEO/owner（5:3 中的 5 AI 起步·关键拍板）
## ⑥ Reflection (human · leader)       ← 人 · leader 团队反思
## ⑦ Execution log (AI · append-only)  ← AI
## ⑧ Feedback (AI · 90 天回填)         ← AI
```

**append-only 强制**：⑤⑥⑦⑧ 节段只能 append·`.githooks/pre-commit` 校验。

**Kevin 规范强制**：所有 `git commit` message 必须含 `[decision: <id>]`·hook 校验·**强制工程纪律**。

### 3.4 · 配置 · `vault/.ome365/eval-config.yml`（行业术语命名）

```yaml
# Per-tenant eval configuration · 5 preset
preset: engineer  # engineer | pm | sales | ops | mixed

# Override（FinOps 2026 行业术语命名 · Fix 6 · D5 25% baked-in HR 偏见已分到 5 preset）
# 5 preset 各自最优权重 · D5 在不同岗位场景占比不同（engineer 重 fork·sales 重 deals）
weights:
  delivery: 0.15              # D1
  cost_per_outcome: 0.15      # D2 · 原 ai_efficacy（已重命名）
  quality: 0.15               # D3
  judgment: 0.10              # D4
  ecosystem: 0.20             # D5 · 默认 20%（preset=engineer 调到 25 / preset=sales 降到 10）
  revenue_per_workflow: 0.15  # D6 · 原 business_impact（preset=sales 调到 30）
  learning: 0.10              # D7

# preset 的 D5 真分（Fix 6 · social proof 偏见根治）
preset_overrides:
  engineer:        # 鼓励技术贡献 · D5 重
    {delivery: 0.10, cost_per_outcome: 0.15, quality: 0.20, judgment: 0.10,
     ecosystem: 0.25, revenue_per_workflow: 0.10, learning: 0.10}
  pm:              # 平衡型 · D4 判断 + D6 业务并重
    {delivery: 0.20, cost_per_outcome: 0.10, quality: 0.10, judgment: 0.20,
     ecosystem: 0.15, revenue_per_workflow: 0.15, learning: 0.10}
  sales:           # 业务结果导向 · D6 重 · D5 轻
    {delivery: 0.15, cost_per_outcome: 0.10, quality: 0.05, judgment: 0.15,
     ecosystem: 0.10, revenue_per_workflow: 0.30, learning: 0.15}
  ops:             # 稳定运营 · D1 / D3 重
    {delivery: 0.25, cost_per_outcome: 0.15, quality: 0.25, judgment: 0.10,
     ecosystem: 0.10, revenue_per_workflow: 0.05, learning: 0.10}
  mixed:           # 默认平衡（同 weights 段）
    {delivery: 0.15, cost_per_outcome: 0.15, quality: 0.15, judgment: 0.10,
     ecosystem: 0.20, revenue_per_workflow: 0.15, learning: 0.10}

# 区域合规
```

### 3.8 · 智能归档 95%/5%（Moxt 学）

```python
def should_keep(file_path, vault):
    score = 0
    score += 5 if recently_accessed(file_path, days=7) else 0
    score += 3 if reference_count(file_path, vault) >= 2 else 0
    score += 2 if linked_from_decision(file_path, vault) else 0
    score += 4 if has_high_adoption(file_path) else 0
    return score >= 5  # 5% 通过
```
